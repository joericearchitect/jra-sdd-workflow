# Industry terms — vocabulary borrowed from other fields

Terms that did not originate in this framework or in spec-driven development,
but are borrowed from other industries and appear in framework code or in
AI/agentic-AI discussions.

## Control plane

The part of a system that *decides and coordinates* — what to do, in what
order, and which tools or agents to use. It is contrasted with the "data plane"
that actually carries out the work. In an agentic system, the control plane is
the layer that plans and orchestrates the agents.

**Terminology Source:** Industry — distributed systems / networking, later
adopted by cloud infrastructure and now AI / agentic AI.

**Related:** data plane

## Data plane

The part of a system that *does the work* — moving the packets, executing the
task, or performing the actual computation — as directed by the control plane.

**Terminology Source:** Industry — distributed systems / networking, later
adopted by cloud infrastructure and now AI / agentic AI.

**Related:** control plane
